# Pink Clean — strona firmy sprzątającej

Landing page w **React + Vite (TypeScript)** dla Pink Clean (Bydgoszcz, Toruń, Nowa Wieś Wielka).

## Uruchomienie

```bash
npm install
npm run dev
```

Produkcja:

```bash
npm run build
npm run preview
```
